Detail mengenai kegagalan tersebut dapat kamu temukan pada catatan code review  di aplikasi submission. Harap periksa catatan tersebut dengan teliti, lakukan perbaikan, dan pastikan semua pengujian berhasil pada submission berikutnya.

Sebelum mengirimkan submission, pastikan kamu melakukan pengujian mandiri terlebih dahulu. Cobalah untuk menghapus dan membuat database berikut dengan tabel serta lakukan migrasi ulang untuk memastikan bahwa semua berjalan dengan baik pada environment yang berbeda.





// src/routes/index.js

import express from 'express';

import userRoutes from './userRoutes.js';

import authRoutes from './authRoutes.js';

 

const router = express.Router();

 

// Semua endpoint user akan langsung di /users

router.use('/users', userRoutes);

router.use('/authentications', authRoutes); // Endpoint login/logout
